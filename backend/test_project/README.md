# React Native Test Project

Этот проект создан для тестирования рендерера файлов в приложении Render MRPAK.

## Структура проекта

```
react-native-project/
├── components/          # Переиспользуемые компоненты
│   ├── Button.jsx      # Кнопка с вариантами стилей
│   ├── Card.jsx        # Карточка для контента
│   └── Header.jsx      # Заголовок экрана
├── screens/            # Экраны приложения
│   ├── HomeScreen.jsx  # Главный экран со счетчиком
│   └── ProfileScreen.jsx # Экран профиля пользователя
├── styles/             # Общие стили
│   └── commonStyles.js # Общие стили и цвета
├── App.jsx            # Главный компонент приложения
└── README.md          # Этот файл
```

## Компоненты

### Button
Кнопка с поддержкой вариантов: `primary`, `secondary`, `danger`.
Используется в экранах для действий пользователя.

### Card
Контейнер для группировки контента с заголовком.

### Header
Заголовок экрана с опциональным подзаголовком.

## Экраны

### HomeScreen
Главный экран с интерактивным счетчиком и кнопками управления.

### ProfileScreen
Экран профиля с информацией о пользователе и действиями.

## Использование

Откройте файл `App.jsx` в рендерере для просмотра всего приложения, или отдельные компоненты/экраны для тестирования зависимостей.

## Зависимости

Проект демонстрирует:
- Импорт компонентов из других файлов
- Использование общих стилей
- Вложенную структуру компонентов
- Состояние и обработчики событий
